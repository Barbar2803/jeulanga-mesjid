PAKET SEO GAMPONG JEULANGA MESJID
====================================

File *.seo.txt berisi blok <head> SEO yang dapat ditempatkan pada masing-masing HTML.
Paket ini TIDAK mengubah CSS/desain.

File:
- index.html.seo.txt
- profil.html.seo.txt
- kependudukan.html.seo.txt
- infografis.html.seo.txt
- pembangunan.html.seo.txt
- data-dokumen.html.seo.txt

Cara memakai di GitHub:
1. Buka file HTML yang sesuai di repository.
2. Klik ikon pensil (Edit).
3. Cari bagian <head>.
4. Ganti <title> lama dengan blok SEO yang sesuai, atau tempel bloknya di dalam <head>.
5. Pastikan <link rel="stylesheet" href="css/style.css"> tetap ada.
6. Commit changes.
7. Tunggu GitHub Pages selesai deploy.
8. Di Google Search Console, inspeksi URL yang berubah lalu minta pengindeksan.

Catatan:
- Nama file logo diasumsikan images/logo-pidie-jaya.png.
- Jika nama/path logo di repository berbeda, ubah URL og:image.
- Jangan menghapus sitemap.xml yang sudah terdaftar di Search Console.
